# UserManager — 2.º DAM
Proyecto educativo SDD, EARS y TDD con OpenCode (Plan y Build). C#, .NET 10, WPF con XAML y code-behind, sin MVVM; JSON local; xUnit; lógica independiente de WPF y del disco en pruebas unitarias.

## Preparación
Git, GitHub CLI (`gh --version`, autenticación humana mediante `gh auth login`, `gh auth status`), OpenCode y SDK .NET 10 en Windows con WPF. Abrir OpenCode desde esta carpeta. No introducir credenciales en prompts ni archivos. Configuración inicial de permisos V2; el profesor debe comprobar compatibilidad con la versión instalada y evitar autoaccept.

## Proceso
Primero elaborar y aprobar constitution.md y AGENTS.md desde sus plantillas; después PRD, índice, todas las specs EARS, arquitectura global, planes y tareas en main. Consolidar y publicar la línea base documental antes de programar. Después una rama por especificación, TDD, revisión independiente, pruebas locales, merge fast-forward local, push exclusivo de feature, PR revisado, merge commit remoto y sincronización. Build solicita autorización para escrituras Git/GitHub. La estructura de código se deduce en Plan, no se entrega.

`docs/DESARROLLO.md` recoge únicamente trabajo realizado; no es contexto técnico. Skills bajo demanda. No usar datos reales.
